# Features

An overview of the features in Shivam Raj's React portfolio.

## Structure

- Sticky navbar with logo, active-section highlighting, Resume button, and mobile menu
- Hero with introduction, profile photo frame, availability badge, CTAs, and social links
- About Me with academic background, interests, quick facts, and career goal
- Experience & Leadership timeline for the ACM Student Chapter role
- Technical Skills in six categories: Programming Languages, Frontend, Backend, Databases, Tools, and Core CS
- Featured Projects grid with cover images, categories, descriptions, tags, and editable links
- Education timeline for the B.Tech CSE degree
- Achievements cards for leadership, hackathons, technical work, and editable certifications
- Coding Profiles cards for GitHub, LeetCode, LinkedIn, and Codeforces
- Let's Connect contact section with details, profiles, and a `mailto:` form
- Footer with auto-updating copyright year, GitHub/LinkedIn, and back-to-top link

## Design

- Dark navy/black theme with blue and purple accents
- Minimal glassmorphism without heavy visual effects
- Space Grotesk display type, Inter body text, and JetBrains Mono labels
- Responsive layouts for mobile, tablet, and desktop
- Subtle scroll reveals with reduced-motion support
- Custom SVG project covers and favicon
- SEO, Open Graph, and Twitter metadata

## Implementation

- React 18 with Vite
- Tailwind CSS with custom night, ink, and accent colors
- Framer Motion for restrained entrance and hover effects
- Lucide React for interface icons
- Centralized editable content in `src/data/content.js`
- Placeholder links rendered in a muted, non-clickable state until real URLs are added
